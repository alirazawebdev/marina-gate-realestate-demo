- Dual video hero (desktop + vertical mobile)
- Property listings with filters (type, area, beds) + sorting
- Property detail pages: image gallery, mortgage calculator, WhatsApp booking
- Agents page, contact → WhatsApp flow
- Fully self-contained static build (videos + images included)
